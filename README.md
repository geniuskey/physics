# 물리 놀이터 ⚛️

**https://physics.euiyun.com** — 던지고, 띄우고, 부딪혀 보는 초심자용 물리 샌드박스.

공식을 몰라도 괜찮아요. 물체를 놓고, 당겼다 놓아 던지고, 버튼 하나로 실험을 돌려 보면서
중력·마찰·물과 바람·전기와 자석·충돌을 손으로 느껴 보는 놀이터입니다.

## 실험 놀이터 (17곳)

| 주제 | 놀이터 |
| --- | --- |
| 🌍 중력 | 누가 먼저 떨어질까? (공기 저항 켜고 끄기) · 행성마다 다른 점프 · 작은 태양계 · 포물선 슛! |
| 🛷 마찰 | 미끄럼틀 대결 (얼음/나무/고무) · 바닥 위 컬링 |
| 💧 물과 바람 | 뜰까, 가라앉을까? (부력) · 물 붓기 놀이 (물방울·물레방아·배) · 바람 터널 |
| ⚡ 전기와 자석 | 밀고 당기는 전기 · 자석 놀이 · 자기장 회오리 |
| 💥 충돌 | 뉴턴의 요람 · 도미노 대행진 · 탑 무너뜨리기 · 당구대 |
| 🧪 자유 | 모든 도구가 있는 자유 놀이터 |

각 놀이터에는 **💡 해보기**(무엇을 눌러 볼지)와 **🤔 왜 그럴까?**(한 줄 설명)가 있어요.

## 도구

잡기 · 공/상자/세모/판자/도미노(재료: 고무·나무·쇠·얼음·돌·풍선·깃털) · 물방울 ·
+/− 전기 · 자석 · 끌개 별 · 벽 긋기 · 막대 줄 · 용수철 · 물웅덩이 · 바람 · 자기장 · 중력 구역 · 펑! · 고정핀 · 지우개

**실험 조건과 예측**: 주요 놀이터(낙하, 행성 점프, 포물선, 자기장)에는 높이·속도·각도·자기장을 바꾸는 슬라이더와
이론값(점선)이 있고, **예측하고 실험하기**로 결과를 먼저 고른 뒤 실험을 돌려 예측과 실제 측정값을 비교할 수 있어요.

**측정** (`M` 키): 물체를 눌러 고르면 질량·높이·속력·가속도·운동량·에너지를 SI 단위로 보여 주고,
위치·속도·에너지를 시간 그래프로 그려요. 기록은 CSV로 내려받을 수 있어요.

설정에서 중력(지구·달·목성·무중력·거꾸로), 공기 저항, 시간 빠르기(¼~2배), 지나간 길, 힘 화살표를 바꿀 수 있어요.
키보드: `Space` 멈춤 · `Ctrl/⌘+Z` 되돌리기 · `M` 측정 · `1`–`9` 도구 고르기.

## 개발

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm test         # 물리 회귀 테스트 + 해석해 검증 (vitest)
npm run build    # 타입 검사 + 테스트 + dist/ 생성
```

- Vite + TypeScript, 강체 충돌은 [matter-js](https://brm.io/matter-js/)
- 단위: 100 px = 1 m, 질량 = kg(밀도 × 10⁶ = kg/m³, 두께 1 cm 판), g = 9.81 m/s². 축척은 `src/units.ts` 한 곳에서 정해요
- 중력(구역별), 부력, 공기 저항(속도에 비례), 쿨롱 힘(실제 k, 60 μC 구슬), 로런츠 힘(속력을 바꾸지 않게 속도를 회전), 별의 인력(GM/r²)은 `src/sim.ts`에서 SI 식으로 계산.
  자석 극·쇠의 자화·바람은 단순화한 모형이에요
- `test/physics.test.ts`: 자유 낙하 √(2h/g), 포물선 사거리, 종단 속도, 원 궤도·케플러 제3법칙, 쿨롱 1/r², 사이클로트론 반지름 mv/qB, 운동량 보존, 부력 평형을 해석해와 비교
- 놀이터 정의는 `src/scenes.ts` — 새 실험은 `SCENES` 배열에 하나 추가하면 돼요.
  `build()` 가 돌려주는 `params`(슬라이더)와 `predict`(질문·보기·`start`·`result`·설명)를 넣으면 실험 조건 카드와 예측 흐름이 붙어요
- 효과음은 Web Audio로 즉석 생성 (`src/audio.ts`)
