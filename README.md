# 물리 실험실

**https://physics.euiyun.com** — 결과를 예측하고, SI 단위로 측정하고, 이론식과 비교하는 중·고등 물리 시뮬레이션.

조건(높이·각도·속력·경사·자기장)을 바꾸고, 결과를 먼저 예측한 뒤 실험을 돌려 측정값을 이론과 비교합니다.
모든 실험에는 쉬운 설명과 함께 **자세히: 식 · 가정 · 한계**가 있어서, 시뮬레이션이 무엇을 단순화했는지도 확인할 수 있어요.

## 실험 (17개)

| 주제 | 실험 |
| --- | --- |
| 중력 | 자유 낙하와 공기 저항 (자유 낙하·공기 저항) · 행성별 중력 가속도 · 궤도 운동 · 포물선 운동 |
| 마찰 | 경사면과 정지 마찰 (tanθ > μs) · 운동 마찰과 제동 거리 (d = v²/2μg) |
| 물과 바람 | 부력과 밀도 (부력) · 물의 흐름과 부력 · 풍동 |
| 전기와 자석 | 쿨롱 힘 · 막대자석과 자기력 · 자기장 속 원운동 |
| 충돌 | 뉴턴의 요람 · 도미노 연쇄 · 진자와 구조물 붕괴 · 2차원 탄성 충돌 |
| 자유 | 모든 도구를 쓰는 자유 실험 |

각 실험에는 **실험 가이드**(해 볼 것), **왜 그럴까?**(쉬운 설명), **자세히**(핵심 식·이 시뮬레이션의 가정·실제와 다른 점)가 있어요.

## 도구

잡기 · 공/상자/세모/판자/도미노(재료: 고무·나무·쇠·얼음·돌·풍선·깃털) · 물방울 ·
+/− 전기 · 자석 · 끌개 별 · 벽 긋기 · 막대 줄 · 용수철 · 물웅덩이 · 바람 · 자기장 · 중력 구역 · 폭발 · 고정핀 · 지우개

**실험 조건과 예측**: 낙하, 행성 점프, 포물선, 경사면 마찰, 컬링, 자기장 실험에는 조건을 바꾸는 슬라이더와
이론값(점선)이 있고, **예측하고 실험하기**로 결과를 먼저 고른 뒤 실험을 돌려 예측과 실제 측정값을 비교할 수 있어요.

**링크 공유**: 상단 링크 단추를 누르면 지금 조건(슬라이더·중력·공기)이 담긴 주소가 복사돼요.
예: `/play/hoops/?deg=40&v=12&g=moon` — 받은 사람은 같은 조건으로 실험을 열어요.

**측정** (`M` 키): 물체를 눌러 고르면 질량·높이·속력·가속도·운동량·에너지를 SI 단위로 보여 주고,
위치·속도·에너지를 시간 그래프로 그려요. 기록은 CSV로 내려받을 수 있어요.

설정에서 중력(지구·달·목성·무중력·거꾸로), 공기 저항, 시간 빠르기(¼~2배), 지나간 길, 힘 화살표를 바꿀 수 있어요.
키보드: `Space` 멈춤 · `Ctrl/⌘+Z` 되돌리기 · `M` 측정 · `1`–`9` 도구 고르기.

## 개발

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm test         # 물리 회귀 테스트 + 해석해 검증 (vitest)
npm run build    # 타입 검사 + 테스트 + dist/ 생성
```

- Vite + TypeScript, 강체 충돌은 [matter-js](https://brm.io/matter-js/)
- 단위: 100 px = 1 m, 질량 = kg(밀도 × 10⁶ = kg/m³, 두께 1 cm 판), g = 9.81 m/s². 축척은 `src/units.ts` 한 곳에서 정해요
- 중력(구역별), 부력, 공기 저항(속도에 비례), 쿨롱 힘(실제 k, 60 μC 구슬), 로런츠 힘(속력을 바꾸지 않게 속도를 회전), 별의 인력(GM/r²), 운동 마찰(μN)·정지 마찰(tanθ ≤ μs)은 `src/sim.ts`에서 SI 식으로 계산.
  자석 극·쇠의 자화·바람은 단순화한 모형이에요
- `test/physics.test.ts`: 자유 낙하 √(2h/g), 포물선 사거리, 종단 속도, 원 궤도·케플러 제3법칙, 쿨롱 1/r², 사이클로트론 반지름 mv/qB, 운동량 보존, 부력 평형, 마찰 제동 거리 v²/2μg 를 해석해와 비교. 예측 실험 6개도 실제로 돌려서 정답이 물리 법칙대로 나오는지 확인해요
- 실험 정의는 `src/scenes.ts` — 새 실험은 `SCENES` 배열에 하나 추가하면 돼요.
  `build()` 가 돌려주는 `params`(슬라이더)와 `predict`(질문·보기·`start`·`result`·설명)를 넣으면 실험 조건 카드와 예측 흐름이 붙어요. 장면의 `deep`(식·가정·한계)은 필수예요
- 링크 공유는 `src/share.ts` (주소 ↔ 조건, 범위·눈금 보정)
- 효과음은 Web Audio로 즉석 생성 (`src/audio.ts`)

## 배포

`main`에 push하면 GitHub Actions가 빌드해서 GitHub Pages로 배포합니다 (`public/CNAME` → `physics.euiyun.com`).

## 검색엔진·링크 미리보기

- 빌드할 때 `vite.config.ts`가 실험마다 `dist/play/<id>/index.html`을 만들어요. 제목·설명·canonical·og 태그·구조화 데이터(JSON-LD)와 읽을 수 있는 본문이 들어 있고, 앱이 뜨면 본문은 실제 화면으로 바뀌어요 (`src/seo.ts`).
- `sitemap.xml`, `robots.txt`, `404.html`(없는 주소도 앱으로)도 같이 만들어요.
- 링크 미리보기 이미지 `public/og/<id>.jpg`는 실험을 더하거나 제목·소개를 바꿨을 때 다시 만들어요: 개발 서버를 띄우고 `BASE=http://127.0.0.1:<포트> ./scripts/og.sh` (macOS + Chrome).
- 예전 `#/play/…` 링크는 새 주소로 옮겨져요.
